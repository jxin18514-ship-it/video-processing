系统 C v2.2 视频处理系统 — 使用说明
========================================

基于 Qwen3-ASR-1.7B 的视频 ASR 转录 + 违禁词检测 + 自动静音管道。


####################################################
##  第一次使用（只需要做一次）
####################################################

【1. 硬件要求】

  GPU：NVIDIA 显卡，8GB 或更大显存
  内存：16GB 或更大
  磁盘：剩余空间 > 输入视频总大小的 3 倍
  系统：Windows 10 或 Windows 11（不支持 Mac / Linux）
  其他：需要提前安装 NVIDIA 显卡驱动和 CUDA Toolkit

【2. 安装 Python】

  如果你的电脑还没有 Python，先去官网下载安装：
    https://www.python.org/downloads/

  安装时一定要勾选 "Add Python to PATH"。
  建议 Python 3.10 或 3.11 版本。

  验证 Python 装好了：
    打开 CMD（命令提示符），输入：
    python --version
    如果显示 Python 3.10.x 或 3.11.x 就说明 OK。

【3. 安装 Python 依赖包】

  打开 CMD，进入本项目文件夹：
    cd 你解压的文件夹路径

  执行：
    pip install -r requirements.txt

  这一步会安装以下包：
    torch（PyTorch，CUDA 版）
    modelscope（魔搭社区，用来下载模型）
    transformers（HuggingFace 模型加载）
    funasr（FunASR 语音识别框架）
    qwen-asr（Qwen3-ASR 官方包）
    opencc（繁简转换）
    pandas（数据处理）
    soundfile（音频读写）
    accelerate（模型加速）
    librosa（音频处理）

  如果下载很慢，可以换国内镜像：
    pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple

【4. 下载模型（约 7 GB，仅首次，耗时取决于网速）】

  打开 CMD，在本项目文件夹下执行：
    python download_models.py

  脚本会自动从魔搭社区（ModelScope）下载 3 个模型：

    模型 1：Qwen3-ASR-1.7B（语音识别主模型）
      大小：约 4.4 GB
      用途：把音频转成文字

    模型 2：Qwen3-Forced-Aligner-0.6B（强制对齐模型）
      大小：约 1.7 GB
      用途：把文字精确对齐到时间点

    模型 3：SenseVoiceSmall（复核模型）
      大小：约 0.9 GB
      用途：对可疑片段进行二次复核

  下载过程中会显示进度，类似：
    [1/3] Downloading Qwen/Qwen3-ASR-1.7B → 03_模型\qwen3-asr-1.7b
    Downloading: 100%|████████████| 4.4G/4.4G [05:23<00:00, 13.6MB/s]
    DONE
    [2/3] Downloading Qwen/Qwen3-Forced-Aligner-0.6B → ...

  如果下载中断（网络问题），直接重新运行 python download_models.py，
  已下载完的模型会自动跳过，从断点继续。

  下载完成后，你会看到：
    All 3 models downloaded to 03_模型\
    Total size: ~7 GB

【5. 环境检查】

  打开 CMD，在本项目文件夹下执行：
    python check_env.py

  它会逐项检查：
    [1] Python 版本
    [2] GPU 是否可用、显存大小
    [3] 所有 Python 依赖是否装齐
    [4] 脚本文件是否完整
    [5] 词库文件是否完整
    [6] 三个模型是否已下载
    [7] 脚本语法是否正确

  看到类似这样的结果就说明一切就绪：
    ============================================================
    结果: 20 PASS — 环境就绪，可以启动批处理

    启动命令（先 dry-run）:
      python 01_脚本\batch_supervisor.py --inbox "你的视频目录" --batch-dir "输出目录" --dry-run
    ============================================================

  如果某些项显示 FAIL，按提示修复后再运行一次 check_env.py。


####################################################
##  日常使用（每次处理视频都这样做）
####################################################

【第一步：准备视频】

  把要处理的 .mp4 或 .ts 视频文件放到一个文件夹里。
  比如：G:\待处理视频\

  建议：
    - 文件名用英文或数字编号，中文有时会出编码问题
    - 不要放其他非视频文件在里面

【第二步：打开 CMD，进入本项目文件夹】

  cd 你解压的文件夹路径

【第三步：dry-run 预览（推荐，先跑这个）】

  基本命令格式：
    python 01_脚本\batch_supervisor.py --inbox "视频所在文件夹" --batch-dir "输出文件夹" --dry-run

  这一步不会启动任何视频处理，只会：
    1. 扫描所有视频
    2. 按文件名前缀自动分组（如 kt(1).ts / kt(2).ts → 组 kt）
    3. 计算每组 target_fps：
       - 全 45fps → 45
       - 全 60fps → 60
       - 45/60 混合 → 45（统一到低帧率）
       - 非标帧率 → BLOCK（不处理）
    4. 生成 logs/group_target_fps.json（分组清单）

  确认 dry-run 输出无误后，再进入正式处理。

【第四步：正式处理】

  基本命令格式：
    python 01_脚本\batch_supervisor.py --inbox "视频所在文件夹" --batch-dir "输出文件夹"

  示例（视频在 G 盘，结果放 D 盘）：
    python 01_脚本\batch_supervisor.py --inbox "G:\待处理视频" --batch-dir "D:\处理结果"

  supervisor 会自动：
    - 按组逐个处理视频
    - 长视频（3h+）处理完冷却 5 分钟再跑下一个
    - 写 supervisor_status.json 追踪每个视频进度
    - 支持中断后续跑

  处理过程：
    每个视频经历 9 个阶段：
      音频提取 → ASR 转录 → 违禁词检测 → 去重审核
      → 坏帧扫描 → 复核 → 幻觉扫描 → CLEAN 审核 → 视频输出
    一个 1 小时的视频大约需要 30-60 分钟处理。

  在 CMD 窗口中可以看到实时进度。

【第五步：查看结果】

  处理完成后，输出目录下每个视频有两个关键文件：

    视频名_cut_final_CLEAN_SYSTEM_C_CUT_V2_01.mp4
      → 处理后的成品视频（已自动静音违规片段）

    视频名_cut_filter_CLEAN_SYSTEM_C_CUT_V2_01.txt
      → 命中的违禁词列表（包含时间点、具体词、静音决定）

【第六步：合并视频（全部 PASS 后）】

  dry-run 预览：
    python 01_脚本\merge_after_process.py --batch-dir "D:\处理结果" --mode FULL_HQ --fps 45 --video-bitrate 10M

  确认无误后执行：
    python 01_脚本\merge_after_process.py --batch-dir "D:\处理结果" --mode FULL_HQ --fps 45 --video-bitrate 10M --merge

  合并规则：
    - FULL_HQ 模式：每组全部 PASS 才合并
    - 参数一致走 -c copy（无重编码，秒级完成）
    - 参数不一致不会自动回退重编码，需人工确认
    - 默认不加 +faststart（本地播放/上传不需要）

【中途中断怎么办？】

  如果处理过程中电脑重启、断电、或手动按了 Ctrl+C：

  不需要做任何特殊操作！直接重新执行相同的命令即可：
    python 01_脚本\batch_supervisor.py --inbox "G:\待处理视频" --batch-dir "D:\处理结果"

  脚本会自动检测哪些视频已经处理完成，跳过它们，从上次中断的地方继续。

  注意：不要换 --batch-dir 路径，必须用同一个输出目录才能续跑。


####################################################
##  注意事项
####################################################

  - 启动批处理前，确保没有其他程序在占用 GPU（关掉游戏、其他 AI 软件等）
  - 磁盘空间要留够：输入视频总大小 × 3
  - Windows 需要安装 Visual C++ 运行库：
    https://aka.ms/vs/17/release/vc_redist.x64.exe
  - 需要安装 CUDA Toolkit（11.8 或更高版本）：
    https://developer.nvidia.com/cuda-downloads
  - 文件夹路径里如果有空格，用双引号包起来，比如 "G:\My Videos"
  - 如果在公司网络环境，可能需要配置代理才能下载模型


####################################################
##  常见问题
####################################################

  Q: pip install 报错？
  A: 试试用国内镜像：
     pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple

  Q: download_models.py 下载到一半断了？
  A: 直接重新运行 python download_models.py，不会重新下载已完成的部分。

  Q: check_env.py 报 "torch not installed"？
  A: 单独安装 PyTorch（CUDA 版）：
     pip install torch --index-url https://download.pytorch.org/whl/cu118

  Q: check_env.py 报 "CUDA available FAIL"？
  A: 检查三件事：
     1. 是否装了 NVIDIA 显卡驱动
     2. 是否装了 CUDA Toolkit
     3. PyTorch 装的不是 CPU 版，是 CUDA 版

  Q: 处理到一半电脑重启了，要重来吗？
  A: 不需要。重新执行相同命令，会自动续跑。

  Q: 跑着跑着报 "CUDA out of memory"？
  A: 显存不够。关闭其他 GPU 程序，重启电脑后再试。

  Q: 最终 MP4 文件打不开？
  A: 不要慌，中间文件还在。用 ffmpeg 从中间文件重建：
     ffmpeg -i 输出目录\视频名_SYSTEM_C_CUT_V2_01\06_output_video\视频名_segments\concat_output.ts -c copy -movflags +faststart 恢复.mp4

  Q: CMD 窗口中文显示乱码？
  A: 在 CMD 窗口输入 chcp 65001 回车，然后再运行命令。

  Q: 运行时 Python 报错 "No module named xxx"？
  A: 重新执行 pip install -r requirements.txt，确保所有包都装上了。
