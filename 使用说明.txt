系统 C v2.2 视频处理系统 — 使用说明
========================================


####################################################
##  第一次使用（只需要做一次）
####################################################

【1. 硬件要求】

  GPU: NVIDIA 8GB+ VRAM
  内存: 16GB+
  磁盘: 输入视频大小 × 3
  系统: Windows 10/11

【2. 安装 Python 依赖】

  pip install -r requirements.txt

【3. 下载模型（约 7 GB，耗时取决于网速）】

  python download_models.py

  会下载 3 个模型到 03_模型/ 目录：
    qwen3-asr-1.7b          (~4.4 GB)
    qwen3-forced-aligner-0.6b (~1.7 GB)
    SenseVoiceSmall         (~0.9 GB)

【4. 环境检查】

  python check_env.py

  看到「全部 PASS」就可以开始用了。


####################################################
##  日常使用（每次处理视频都这样做）
####################################################

【输入视频准备】

  把要处理的 .mp4 或 .ts 视频放到一个文件夹里。
  建议文件名用英文/数字，避免中文特殊字符。

【启动处理】

  python 01_脚本\batch_system_c_cut_v2.py --inbox "视频所在文件夹" --batch-dir "输出文件夹"

  示例：
    python 01_脚本\batch_system_c_cut_v2.py --inbox "G:\直播视频\今天" --batch-dir "D:\处理结果"

  参数：
    --inbox       视频输入目录
    --batch-dir   结果输出目录
    --force       强制全部重跑（一般不需要）
    --limit N     只处理前 N 个视频

【中断后继续】

  直接重新执行相同命令，已处理完的视频会自动跳过：
    python 01_脚本\batch_system_c_cut_v2.py --inbox "G:\直播视频\今天" --batch-dir "D:\处理结果"

【输出结果】

  每个视频在输出目录下生成：
    视频名_SYSTEM_C_CUT_V2_01\
    视频名_cut_final_CLEAN_SYSTEM_C_CUT_V2_01.mp4  ← 最终成品
    视频名_cut_filter_CLEAN_SYSTEM_C_CUT_V2_01.txt ← 违禁词命中列表


####################################################
##  注意事项
####################################################

  - 启动前关闭其他 GPU 程序，确保显存充足
  - 磁盘空间：输入视频总大小 × 3
  - Windows 需要安装 Visual C++ 运行库和 CUDA Toolkit


####################################################
##  常见问题
####################################################

  Q: 处理到一半电脑重启了？
  A: 重新执行相同命令，会自动续跑，不会重复处理。

  Q: 最终 MP4 打不开？
  A: 中间文件还在。用 ffmpeg 从中间文件重建：
     ffmpeg -i 输出目录\视频名_SYSTEM_C_CUT_V2_01\06_output_video\视频名_segments\concat_output.ts -c copy -movflags +faststart 恢复.mp4

  Q: 显存不够？
  A: 关闭其他 GPU 程序后再试。至少需要 8GB VRAM。

  Q: check_env.py 报某个依赖未安装？
  A: pip install 对应的包，或重新 pip install -r requirements.txt
